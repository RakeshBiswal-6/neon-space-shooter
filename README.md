# NEON STRIKE — Rakesh Biswal

A responsive neon space-shooter arcade mini-game built with vanilla HTML5, CSS3, and JavaScript (Canvas).

## 🚀 Live Demo
Play online: **https://rakeshbiswal-6.github.io/neon-space-shooter/**

## 🎮 Controls
- **Move:** `←` / `→` or `A` / `D`
- **Fire:** `Spacebar` (or on-screen touch button on mobile)
- **Pause:** `P`
- **Start / Restart:** `Enter` or click "Start Mission"

## 🛠️ Tech Stack
- HTML5 Canvas API
- CSS3 Neon Aesthetics & Keyframe Animations
- JavaScript (ES6+, Game Loop, Collision Physics, Particle Engine)
